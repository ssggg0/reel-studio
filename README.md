# 릴 스튜디오 — 성현님 전용 쇼츠 스튜디오

`https://ssggg0.github.io/reel-studio/`

소재 발굴 → AI 대본 → 원본·자막 → BGM·보이스 → 실시간 미리보기 → 영상 렌더 → 썸네일 → 유튜브 업로드까지 한 화면에서 끝내는 개인용 쇼츠 스튜디오입니다.
화이트·인디고 테마의 5단계 스텝퍼 UI이며, 모든 핵심 동작은 **한 번 누르는 원클릭**으로 처리됩니다.

- **결제·크레딧·구독·로그인 없음.** 내 브라우저(localStorage)에 내 API 키만 넣어 씁니다.
- **API 키가 없어도 전부 체험 가능.** 샘플 소스·데모 대본·샘플 떡상 데이터로 대본 수정, 원클릭 스타일, BGM, 미리보기, 영상 렌더, 썸네일, 0오류 점검까지 그대로 동작합니다.
- **아이폰(390×844) 우선** 모바일 UI + PC 데스크톱 레이아웃.

## 5개 단계

1. **소재 발굴** — `🔥 한국 떡상` `🇺🇸 미국 바이럴` `🇯🇵 일본 떡상` `🐾 동물·힐링` `🤖 AI·테크` 원클릭 프리셋과 `🐾 고양이·강아지` `🎭 해외밈·반전` `📹 CCTV·블랙박스` `💡 생활꿀팁` `🗾 일본·해외일상` `✨ 신기한 현상` 검색 칩. `분석`·프리셋·칩을 누르면 **결과 자리로 자동 스크롤**되며 12건이 바로 뜨고(데모에서도 어떤 단어든 연관·비슷한 결·추천으로 채웁니다), 카드마다 `대본 세팅 →` `원본 열기 ↗` `링크 복사` `원작자 찾기`가 붙습니다. 그 아래 **📦 무가공 클린 원본 12편**과 **🔥 지금 터지는 인기 쇼츠 가로 레일**(9:16 카드·조회수 배지·카테고리 태그 14종)이 있어 옆으로 넘기며 보고, 카드를 누르면 훅·대본·댓글이 깔리면서 원본·대본 탭 상단에 **원본 영상 열기 + 내 파일 올리기(드롭존) 패널**이 뜹니다. 키가 없으면 2026-11-27 YouTube 인기 쇼츠 조회수 기준 샘플 16종, 키가 있으면 `videoDuration=short·order=viewCount` 실시간 결과를 씁니다.
2. **원본·대본** — **슬림 큐 카드**: 한 줄에 `번호 · 문장 · ▶ · ⚙ · ✕`, 그 아래 작은 메타(`0.0~3.2s · 효과음 · 댓글`). `⚙`나 메타를 누르면 시작/끝·효과음·댓글이 아코디언으로 펼쳐져 모바일 한 화면에 6개 이상 보입니다. **편집 스타일 8종**: 옆으로 스와이프되는 컴팩트 레일(카드 폭 116~126px)에 실제 캔버스 미리보기·배속 배지가 붙어 있고, 카드를 **딸깍**하면 띠·자막·강조색·색감·배속·댓글 카드가 한 번에 전환됩니다(아래 ‘스타일 프리셋’ 표 참고). **원클릭 대본 도구**: `✨ 음슴체 제거`, `🎯 숫자·핵심어 강조`, `⏱️ 25초 템포 맞춤`. 그 아래 큐 카드에서 문장·시간·효과음·댓글을 직접 수정.
3. **음원·보이스** — **내 보이스 보관함**: mp3·wav·m4a를 여러 개 끌어다 놓고(IndexedDB 저장) `▶ 미리듣기` → 카드를 **딸깍**하면 배속(1.0~1.3x)·볼륨과 함께 미리보기·MP4 렌더에 바로 섞입니다. `📋 대본 1초 복사 + 타입캐스트 열기`로 나레이션 문장만 복사해 바로 생성. 그 아래 **무저작권 BGM 5종**(누르면 바로 들리면서 적용, 덕킹)과 **🔊 새 효과음 100종**: 검색 + 6개 카테고리(전체·타격·폭발·웃음·밈·UI·알림·전환·기타) 칩으로 골라 **카드 딸깍 → 고른 큐의 시작 시점에 삽입**, `▶`는 미리듣기. mp3를 미리 디코딩(AudioBuffer 캐시)해 미리보기와 MP4 렌더 오디오(recDest)에 지연 없이 믹싱합니다. 브라우저 TTS·API TTS 설정은 2026-11-27 제거(타입캐스트 mp3만 사용).
4. **미리보기·내보내기** — 9:16/16:9 캔버스 합성, 재생·스크럽, **🔍 0오류 자동 점검**(하단 UI 세이프존 y≥1420 · 자막 잘림 · 훅 2줄 초과 · 음슴체 · 시간 겹침/공백)과 **🛠 원클릭 자동 수정**, Canvas+MediaRecorder 렌더(720p/1080p), 1080×1920 썸네일 PNG.
5. **유튜브 업로드** — Google OAuth(YouTube Data API `videos.insert` resumable upload)로 비공개/일부공개/공개 업로드.

## 🛡️ 수익화 위험 영상 자동 제외 (기본 ON)

발굴 탭 검색 카드의 `🛡️ 방송·아이돌·랭킹 자동 제외` 뱃지는 **켜져 있는 게 기본**이고, 한 번 누르면 그 자리에서 꺼집니다(설정은 `localStorage` `reelstudio.safeFilter.v1`).

- **거르는 것** — ① 국내외 방송사·예능·뉴스·드라마 클립(`KBS` `MBC` `SBS` `JTBC` `tvN` `채널A` `TV조선` `MBN` `YTN` `연합뉴스` `스브스` `디글` `엠뚜루마뚜루` `예능` `드라마` `명장면` `하이라이트` `클립` `풀영상` `예고편` 등) ② 아이돌·K-POP·음방·기획사(`아이돌` `직캠` `fancam` `STUDIO CHOOM` `1theK` `MBCkpop` `인기가요` `뮤직뱅크` `엠카운트다운` `HYBE` `SMTOWN` `JYP` `YG` `BLACKPINK` `BTS` `Official MV` 등) ③ 영화·OTT 저작권물(`Netflix` `디즈니` `Marvel` `쿠팡플레이` `티빙` `왓챠` `애니메이션` `트레일러` 등) ④ **여러 장면 짜깁기 랭킹·모음집**(`랭킹` `순위` `TOP` `탑` `모음` `모음집` `총정리` `결산` `compilation` `best of` `외 다수` — 단일 장면·단일 원본으로 따라 만들 수 있는 소재만 남기기 위함).
- **동작 위치** — `js/safe-filter.js`(사전·판정), `js/tube.js`(검색·인기 레일 결과를 뒤에서 한 번 더 거름, 1페이지 50건 + 필요하면 2페이지 보충), `js/core.js`(샘플 38→31건·인기 레일 16건 정리 + 2차 방어선), `js/app.js`(뱃지·토글·상태줄).
- **표시** — 상태줄에 `🛡️ 방송·아이돌·랭킹 등 위험 N건 자동 제외`, 인기 레일 머리에 `🛡️ 위험 N건 제외` 칩. 전부 걸러져 결과가 비면 `자동 제외 끄고 보기` 버튼이 뜹니다. 샘플 모드에서 `예능`·`아이돌`·`모음`처럼 위험 키워드로 검색하면 상태줄이 그 사실을 짚어 줍니다.
- **🌍 해외 밈·글로벌 클립 우선** — 발굴 기본 추천 12건·인기 레일·검색 결과를 `RS.rank.mix()`가 4칸 중 3칸(약 75%) 해외 밈/글로벌 동물 클립으로 채웁니다(최신순 정렬은 그대로).

## 무가공 클린 원본 12편 (`originals/`)

발굴 탭의 **📦 바로 쓰는 무가공 클린 원본** 섹션은 자막·로고를 덧입히지 않은 원본 MP4 12편(총 68MB, 낱개 1.6~13.8MB)을 사이트에 직접 싣고 있습니다.

| 카드 버튼 | 동작 |
|---|---|
| **⬇ 원본 다운** | `<a download>`로 MP4를 그대로 내려받습니다(아이폰 ‘파일’ 앱 → 앨범·캡컷). |
| **🎬 바로 얹기** | `fetch()`로 MP4를 받아(진행률 표시) 편집기의 원본 영상으로 즉시 세팅하고 **2단계 원본·대본**으로 넘깁니다. 다운로드 → 다시 올리기가 필요 없습니다. |

- 구성: 해외밈 6편(`meme01~06` — 창문 벌레·음주운전 반전·영어 알아듣는 고양이·자메이카 액센트·시간 멈추기·기자회견) + 고양이 6편(`cat01~06` — 쿵푸·휴지 자르기·티슈 치기·그물모자·메인쿤 목욕·검은 고양이).
- `originals/manifest.json`(제목·카테고리·길이·해상도·추천 훅·원작자·검색어)이 원본이고, 페이지는 `js/originals-data.js`로 같은 내용을 읽습니다. 다시 만들려면 `python3 dev/build_originals.py`(원본 소스: `downloads/hipplug_batch3`, `downloads/tiktok_cute_cat_10`).
- 유튜브 실시간 검색 결과는 정적 페이지·약관상 MP4 직다운로드가 불가하므로 카드에 **원본 열기 ↗ · 링크 복사 · 원작자 찾기**(YouTube/TikTok 검색)만 붙습니다.
- 원작자 영어 캡션이 원본에 구워진 클립이 일부 있습니다(합성·워터마크 없음). 재사용 전 원작자 이용 조건을 확인하세요.

## ⑤ 마무리 · 피클로 넘기기 (2026-11-28 개편)

사이트에서 유튜브로 직접 올리던 OAuth 업로드(`publishAt` 예약 포함)는 **넣지 않습니다**. 대신 5단계에서 파일과 메타를 정리해 참외(피클) 채팅으로 넘기면, 참외가 최종 검수·유튜브 저작권 '문제없음' 확인·업로드/예약까지 처리합니다.

- **제목 5안** — 호기심형·숫자·충격형·반전형·썰형·질문형. 한 번 누르면 제목 칸에 바로 반영. Gemini 키가 있으면 `🤖 AI로 5안`, 없거나 실패하면 훅·대본 기반 기본 5안.
- **썸네일 생성기** — 1080×1920 캔버스, 3스타일(`🔥 다큐 고대비` · `⚡ 도파민 레드/옐로` · `🤍 화이트 카드`), 문구·작은 줄 수정, `#단어` 포인트 색, `⬇ 썸네일 저장 (PNG)`. 배경은 업로드 사진 → 현재 영상 프레임 → 샘플 순서.
- **올리기 전 3줄 체크** — ① 금지어·비속어 ② 저작권 위험 소재(방송·아이돌·영화·랭킹) ③ 설명란 “출처 · 원작자 요청 시 즉시 삭제합니다”. 설명란에는 이 문구가 자동으로 들어갑니다.
- **🥒 피클로 넘기기** — `⬇ 완성 MP4 저장` · `⬇ 썸네일 PNG 저장` · `📋 제목·설명 복사`.

## 세이프존 · 점검 규칙

- `RS.safe`(js/core.js): 자막 최대 폭 76%, 댓글 카드 70%, 하단 한계 y **1400**(1080×1920 기준), 카드 오른쪽 끝 88%. 렌더(`render.js`)와 점검(`app.js`)이 같은 값을 써서 **자막·카드가 유튜브 우측 아이콘/하단 UI를 침범하지 않습니다**.
- 음슴체 검출은 어미(`~함·~됨·~임·~짐·~음·~움·~픔·~름`)로 판단하고 명사(`처음·마음·이름·다음·구름` 등)는 제외합니다. `안 됨`처럼 한 글자 어미도 잡습니다.
- `원클릭 자동 수정`은 음슴체 → 구어체, 3줄 이상 자막 분리, 훅 글자 축소, 세이프존 위로 이동, 큐 시간 겹침·공백 정리를 한 번에 합니다.
