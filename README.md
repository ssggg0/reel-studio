# 릴 스튜디오 — 성현님 전용 쇼츠 스튜디오

`https://ssggg0.github.io/reel-studio/`

소재 발굴 → AI 대본 → 원본·자막 → BGM·보이스 → 실시간 미리보기 → 영상 렌더 → 썸네일 → 유튜브 업로드까지 한 화면에서 끝내는 개인용 쇼츠 스튜디오입니다.

- **결제·크레딧·구독·로그인 없음.** 내 브라우저(localStorage)에 내 API 키만 넣어 씁니다.
- **API 키가 없어도 전부 체험 가능.** 샘플 소스·데모 대본·샘플 떡상 데이터로 대본 수정, BGM, 미리보기, 영상 렌더, 썸네일까지 그대로 동작합니다.
- **아이폰(390×844) 우선** 모바일 UI + PC 데스크톱 레이아웃.

## 5개 탭

1. **발굴** — 키워드·지역·길이·최소 조회수·정렬(떡상률/조회수/최신)로 유튜브를 훑고, 조회수÷구독자로 뜬 영상만 골라 대본 탭으로 가져옵니다. 키가 없으면 내장 샘플 12건.
2. **대본** — mp4/mov/webm 업로드 또는 샘플 소스(다큐·차트·네온·페이퍼) 선택, 세로 크롭·확대·색감. AI 대본(훅 2줄 + 9큐 + 제목 3안 + 설명·태그), 다국어 번역. 큐별 텍스트·시작/끝·효과음·댓글 카드 직접 수정. SRT 복사.
3. **음원** — 직접 합성한 무저작권 BGM 5종(긴장감·다큐·트렌디·유머·감성) 미리듣기/삽입, 볼륨·보이스 덕킹, 브라우저 TTS + 나레이션 파일 업로드, 효과음 4종(팝·휙·밑줄·알림).
4. **미리보기·내보내기** — 9:16/16:9 캔버스에 원본+훅+자막+댓글카드+BGM을 실시간 합성, Canvas+MediaRecorder로 실제 영상 렌더(720p/1080p, 30/60fps), 1080×1920 썸네일 PNG·제목/설명/태그 복사.
5. **업로드** — Google OAuth(YouTube Data API `videos.insert` resumable upload)로 비공개/일부공개/공개 업로드.

## API 키 (설정 ⚙︎)

| 키 | 쓰임 | 발급 |
|---|---|---|
| YouTube Data API v3 | 소재 발굴 실데이터 | [Cloud 콘솔](https://console.cloud.google.com/apis/library/youtube.googleapis.com) → API 키 (무료 10,000유닛/일) |
| Gemini API | AI 대본·번역 | [AI Studio](https://aistudio.google.com/apikey) (무료 티어) |
| Google OAuth Client ID | 유튜브 업로드 | Cloud 콘솔 → OAuth 클라이언트 ID(웹), 승인된 JavaScript 원본 `https://ssggg0.github.io` |

키는 이 브라우저의 localStorage에만 저장되고 어디로도 전송되지 않습니다.

## 스타일 프리셋

이슈한잔(다크·중앙정렬·라임 강조) / 힙플러그(흰 제목 카드·검정 자막 박스·세로 핸들) / 짤주웠어(상단 검은 띠·직각 댓글 카드) / 날것 도파민. 현재 스타일을 이름 붙여 저장하고 JSON으로 내보낼 수 있습니다.

## 개발 메모

- 빌드 없음. 정적 파일 그대로 GitHub Pages.
- `index.html` + `css/style.css` + `js/{core,audio,render,ai,tube,app}.js`
- `dev/mobile-frame.html` — 390×844/430×932 뷰포트 검수용 프레임(배포 후 QA에 사용).
- 아이폰 Safari는 렌더 결과가 mp4, 크롬은 webm입니다. 렌더 중 화면을 끄면 녹화가 끊깁니다.
- 브라우저 TTS는 미리듣기용입니다. 실제 영상에 목소리를 넣으려면 타입캐스트 mp3를 `나레이션 오디오 올리기`로 얹으세요 (BGM·효과음과 함께 렌더에 섞입니다).
