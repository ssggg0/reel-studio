# 릴 스튜디오 — 성현님 전용 쇼츠 스튜디오

`https://ssggg0.github.io/reel-studio/`

소재 발굴 → AI 대본 → 원본·자막 → BGM·보이스 → 실시간 미리보기 → 영상 렌더 → 썸네일 → 유튜브 업로드까지 한 화면에서 끝내는 개인용 쇼츠 스튜디오입니다.
화이트·인디고 테마의 5단계 스텝퍼 UI이며, 모든 핵심 동작은 **한 번 누르는 원클릭**으로 처리됩니다.

- **결제·크레딧·구독·로그인 없음.** 내 브라우저(localStorage)에 내 API 키만 넣어 씁니다.
- **API 키가 없어도 전부 체험 가능.** 샘플 소스·데모 대본·샘플 떡상 데이터로 대본 수정, 원클릭 스타일, BGM, 미리보기, 영상 렌더, 썸네일, 0오류 점검까지 그대로 동작합니다.
- **아이폰(390×844) 우선** 모바일 UI + PC 데스크톱 레이아웃.

## 5개 단계

1. **소재 발굴** — `🔥 한국 떡상` `🇺🇸 미국 바이럴` `🇯🇵 일본 떡상` `🐾 동물·힐링` `🤖 AI·테크` 원클릭 프리셋과 `🐾 고양이·강아지` `🎭 해외밈·반전` `📹 CCTV·블랙박스` `💡 생활꿀팁` `🗾 일본·해외일상` `✨ 신기한 현상` 검색 칩. 그 아래 **🔥 지금 터지는 인기 쇼츠 가로 레일**(9:16 카드·조회수 배지·카테고리 태그 14종)이 있어 옆으로 넘기며 보고, 카드를 누르면 훅·대본·댓글이 깔리면서 원본·대본 탭 상단에 **원본 영상 열기 + 내 파일 올리기(드롭존) 패널**이 뜹니다. 키가 없으면 2026-11-27 YouTube 인기 쇼츠 조회수 기준 샘플 16종, 키가 있으면 `videoDuration=short·order=viewCount` 실시간 결과를 씁니다.
2. **원본·대본** — **슬림 큐 카드**: 한 줄에 `번호 · 문장 · ▶ · ⚙ · ✕`, 그 아래 작은 메타(`0.0~3.2s · 효과음 · 댓글`). `⚙`나 메타를 누르면 시작/끝·효과음·댓글이 아코디언으로 펼쳐져 모바일 한 화면에 6개 이상 보입니다. **편집 스타일 4종**(이슈한잔·힙플러그·짤주웠어·날것 도파민)을 미리보기 배지가 있는 카드로 눌러 상단 띠·자막·강조색·색감·배속·댓글 카드를 한 번에 전환. **원클릭 대본 도구**: `✨ 음슴체 제거`, `🎯 숫자·핵심어 강조`, `⏱️ 25초 템포 맞춤`. 그 아래 큐 카드에서 문장·시간·효과음·댓글을 직접 수정.
3. **음원·보이스** — **내 보이스 보관함**: mp3·wav·m4a를 여러 개 끌어다 놓고(IndexedDB 저장) `▶ 미리듣기` → 카드를 **딸깍**하면 배속(1.0~1.3x)·볼륨과 함께 미리보기·MP4 렌더에 바로 섞입니다. `📋 대본 1초 복사 + 타입캐스트 열기`로 나레이션 문장만 복사해 바로 생성. 그 아래 **무저작권 BGM 5종**(누르면 바로 들리면서 적용, 덕킹)과 **🔊 새 효과음 100종**: 검색 + 6개 카테고리(전체·타격·폭발·웃음·밈·UI·알림·전환·기타) 칩으로 골라 **카드 딸깍 → 고른 큐의 시작 시점에 삽입**, `▶`는 미리듣기. mp3를 미리 디코딩(AudioBuffer 캐시)해 미리보기와 MP4 렌더 오디오(recDest)에 지연 없이 믹싱합니다. 브라우저 TTS·API TTS 설정은 2026-11-27 제거(타입캐스트 mp3만 사용).
4. **미리보기·내보내기** — 9:16/16:9 캔버스 합성, 재생·스크럽, **🔍 0오류 자동 점검**(하단 UI 세이프존 y≥1420 · 자막 잘림 · 훅 2줄 초과 · 음슴체 · 시간 겹침/공백)과 **🛠 원클릭 자동 수정**, Canvas+MediaRecorder 렌더(720p/1080p), 1080×1920 썸네일 PNG.
5. **유튜브 업로드** — Google OAuth(YouTube Data API `videos.insert` resumable upload)로 비공개/일부공개/공개 업로드.

## API 키 (설정 ⚙)

| 키 | 쓰임 | 발급 |
|---|---|---|
| YouTube Data API v3 | 소재 발굴 실데이터 | [Cloud 콘솔](https://console.cloud.google.com/apis/library/youtube.googleapis.com) → API 키 (무료 10,000유닛/일) |
| Gemini API | AI 대본·번역 | [AI Studio](https://aistudio.google.com/apikey) (무료 티어) |
| Google OAuth Client ID | 유튜브 업로드 | Cloud 콘솔 → OAuth 클라이언트 ID(웹), 승인된 JavaScript 원본 `https://ssggg0.github.io` |

키는 이 브라우저의 localStorage에만 저장되고 어디로도 전송되지 않습니다.

## 효과음 100종

- `sfx/` — MP3 100개(44.1kHz 스테레오 128kbps, 3.2MB) + `manifest.json`, 인덱스는 `js/sfx-pack.js`
- 출처: `youtube.com/watch?v=2P6QerHOCGE` — *Top 100 Sound Effects For Editing (2026)* (MrShark6000). 이용 전 원본 채널의 이용 조건을 확인하세요.
- 각 항목에 음량 보정 게인(`g`)이 들어 있어 작은 소리(딸깍 −28dB)와 큰 소리(폭발 −16dB)가 같은 체감 음량으로 섞입니다(피크 −0.5dB 제한).
- 큐별로 기본 합성 효과음 4종(팝·휙·밑줄·알림)과 100종을 함께 고를 수 있습니다(대본 탭 `⚙` → 효과음, 카테고리별 optgroup).

- `index.html` + `css/style.css` + `js/{sfx-pack,core,audio,render,ai,tube,app}.js`
